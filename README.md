# Portrait Coach

See a reference photo over your phone's camera view and trace it onto paper.

- Choose a photo, turn on the camera, and set how see-through the photo is.
- Drag to move, pinch to zoom, twist with two fingers to rotate, double-tap to fit. Lock stops accidental moves.
- A spirit level shows when the phone is parallel to the paper. For a sloped board, lay the phone on the paper and tap Calibrate.

Plain HTML, CSS and JS. No build step. Photos stay in the browser.

```
python3 -m http.server   # then open http://localhost:8000
```

Deployed to GitHub Pages by `.github/workflows/pages.yml` on every push to `main`.
